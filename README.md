# Ascendant Survival Addon

Addon modular para Minecraft Bedrock focado em desempenho, utilidades técnicas e automação via Script API.

## 🛠️ Funcionalidades (v1.1.5)
- **Suite de Ferramentas (`utilities.js`):**
  - Mineração em cascata (Vein Miner).
  - Corte progressivo de árvores e folhagens.
  - Escavação em área 3x3.
  - Aração e cultivo 3x3.
  - Ímã global com atração suave e teleporte instantâneo.
  - Perfis dinâmicos de velocidade/desempenho.
- **Tocador de Música:**
  - Interface acessível agachando e saltando de mãos vazias.
